# First Poly

This is a Java project demonstrating **polymorphism** using an object-oriented approach.  
It includes different sports-related classes (e.g., Football, Hockey, Golf) that extend a base `Athlete` class.

## Features
- Abstract classes and interfaces
- Method overriding
- UML diagram included
- Clean separation between `src/` and compiled files

## How to Run
This project was built using Eclipse.  
Just import the project into Eclipse and run the `Main` class inside the `src/` folder.
